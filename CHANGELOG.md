# Historial de versiones

Los detalles completos están en los commits de GitHub. Este archivo resume los cambios que afectan a quienes visitan o mantienen el sitio.

## 2.0.0 — 2026-09-28

- Se adopta `PRAM-atencion-clientes-v5.html` como fuente de la versión activa.
- Todo el sitio vuelve a funcionar desde un único `index.html`.
- La portada muestra “Bienvenidos a PRAM” y “Conocer PRAM” lleva al contenido del proyecto dentro del mismo archivo.
- Las fotografías optimizadas se mantienen en `assets/isimiya/`.
- Se elimina el enlace provisional de Instagram porque no tenía una dirección válida.
- Se prepara la publicación en Vercel y una verificación automática del sitio.

## 1.x — 2026-09-27

- Versión multipágina para Feria TP.
- Incorporación de recursos visuales, herramientas de atención y mejoras para celulares.
- Publicación automática en GitHub Pages.
